# Projeto Zelda TOTK — HTML puro

Site acadêmico sobre The Legend of Zelda: Tears of the Kingdom, desenvolvido somente com HTML.

## Estrutura
- `html/`: quatro páginas do site.
- `img/`: ilustração SVG local.
- `audio/`: áudio WAV local demonstrativo.
- `video/`: pasta reservada para vídeo local.

## Como abrir
Abra `html/index.html` no navegador ou abra a pasta principal no VS Code.

## Páginas
- `index.html`: apresentação e ficha técnica.
- `historia.html`: contexto e personagens.
- `gameplay.html`: habilidades e tabela.
- `exploracao.html`: regiões e formulário.

- O projeto não contém CSS.
